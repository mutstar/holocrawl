# 전투 도트 1차 통합 — combat-art01

내장 image_gen으로 소환물 → 권능 이펙트 → 상태 아이콘 → 인간 플레이어 기본 체형 순서로 네 장의 원화를 생성했다. 전체 프롬프트는 `generation-prompts.json`, 생성 원화는 `originals/`에 보관했다. 세밀한 원화 축소 느낌을 줄이도록 굵은 윤곽과 단순한 색면을 요청했다. 엄격한 수작업 도트·고정 팔레트 규격을 보장하는 생성 방식은 아니다.

게임에 사용하는 원본은 모두 32×32 RGBA PNG다. `scripts/import-combat-art01.py`는 원화 셀 자르기·최근접 축소·배치만 한다. 생성 원화의 거의 보이지 않는 알파 잡음은 자르기 영역을 정할 때 제외하지만 실제 잘라온 픽셀·알파는 유지한다. 까마귀 칸의 인접 칸 조각은 본체의 연결 영역을 기준으로 자르기 경계를 정해 제외했다.

- `creature-preview.png`: 장미·여우·까마귀·검사·사냥개 각각 2프레임, 10개. 원래의 아군·적 표시를 그대로 사용한다. 검사와 사냥개는 현재 징벌 소환물이다.
- `effect-preview.png`: 16종 × 2프레임, 32개. 바닥과 몬스터를 가리지 않게 중앙을 비워두고 테두리·파문·불씨 위주로 구성했다. 도깨비불은 청록·보라색으로 통일했다.
- `status-preview.png`: 8개 상태 도형을 8×8 이내로 축소한 뒤 캐릭터 타일의 네 모서리에 배치한다. 위왼쪽은 5성/일반 권능 활성, 아래왼쪽은 보호, 위오른쪽은 징벌 경고/긴급/활성, 아래오른쪽은 회복 대기/자원이다. 동시에 최대 네 개만 표시한다.
- `player-preview.png`: 인간 기본 체형 2개. 기존 갑옷·무기·방패·모자·신발 레이어를 유지하며 렌더링 복사본의 기본 몸체만 바꾼다. 다른 종족·변신·사용자 지정 몬스터 타일은 원래 모습을 사용한다.
- `faith-charm-preview.png`: 이전에 생성한 22신 메뉴 문양을 8픽셀 이내로 가져와 장식 레이어에 배치했다. 장식은 별도 그림을 다시 생성한 것이 아니라 기존 심볼을 재사용한다. 징벌 표시는 같은 모서리의 신 표식보다 위에 그린다.

총 74개 가져오기 대상: 소환물 10 + 이펙트 32 + 상태 8 + 인간 체형 2 + 신 표식 22. `manifest.json`에 경로·SHA256을 기록한다. 이번 단계에서는 기존 제단 22개와 메뉴 신 문양을 변경하지 않는다.
