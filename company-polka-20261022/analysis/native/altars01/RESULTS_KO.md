# 제단 구조물 교체 — altars01

기존 구현은 동일한 원본 제단 위에 신별 문양을 덧씌웠다. 이번에는 22신의 독립된 전체 구조물 타일을 만들고 `tileidx_feature`에서 원본 제단 타일을 교체한다. 문양 오버레이는 제거했다. 메뉴의 신별 문양은 유지한다.

스이세이 운석 결정, 미코 토리이, 아키 장미 아치, 후부키 여우 석등, 아야메 검 거치대, 초코 하트 솥, 코로네 샌드백, 오카유 고양이 방석, 페코라 토끼굴, 노엘 방패, 와타메 양털 둥지, 토와 날개 수정, 라미 얼음 술통, 폴카 천막, 코요리 실험대, 루이 까마귀 횃대, 라덴 병풍, 하지메 북, 스우 분수, 비비 거울, 소피아 천체 모형, 메라 화로로 구분한다.

가입한 제단에 저장하던 신 ID를 그대로 사용한다. 저장 형식과 숭배 규칙은 바꾸지 않았다. 원본 신의 제단은 Holo 신이 연결되기 전까지 기존 외형이다. 모든 일반 제단을 무조건 새 신으로 바꾸는 작업은 아니다.

검증: 문자·SDL 빌드 성공. 두 실행본의 22신 권능/시각 상태/저장/새 프로세스 복원 검사가 통과했다. SDL에서 22개 제단 전체를 한 화면에 배치해 원본 받침대와 문양 오버레이가 남지 않았음을 직접 확인했다. 모든 제단 ID의 연속성과 잘못된 ID 처리도 검사한다. 문자 저장을 SDL 실행본에서 읽는 검사도 통과했다. 새 RGBA 타일은 22개 모두 32×32이며 파일 해시가 서로 다르다.

이번 변경은 외형만 다룬다. 이전 322개 고정 전투 일치 결과는 tiles01의 이력이며 이번 단계에서 다시 실행하지 않았다. 봇 승률 검증은 계속 보류한다.

- 현재 실행: `PLAY_HOLOCRAWL.cmd` → `runtime/tiles01/HoloCrawl.exe` (갱신됨)
- 게임 화면: `analysis/native/tiles01/altars01-sdl/god-altars.png`
- SDL 검사: `analysis/native/tiles01/altars01-sdl/manifest.json`
- 문자 검사: `analysis/native/campaign-abilities01/altars01-console/manifest.json`
- 원화·게임 타일 미리보기·프롬프트: `assets/holocrawl/altars01/`
- 현재 상태: `engine/campaign_status.json`
- 이전 상태와 실행본은 `analysis/native/tiles01/`에 보존했다.
