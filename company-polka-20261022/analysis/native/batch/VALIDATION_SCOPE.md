# 22신 전투 코어 일괄 검증 범위

이 배치는 일반 플레이어가 신을 선택해 저장·불러오기 하는 완성 모드에 앞서, DCSS 0.24.0의 실제 전투와 각 신의 전투 효과를 비교하는 headless 시험이다. 기본 수치 원본은 `HOLOCRAWL_DESIGN.md`이며, 최종 데이터 옆 design.md 스냅샷과 소스 패치 해시로 실행 버전을 고정한다.

공통: Human 고정 HP/MP/기도술·장비, 원작 명중/EV/AC/GDR/방패/몬스터 AI/세계 시간/자연 회복을 사용한다. 원거리 공격은 `throw_it`, 주문은 `cast_a_spell`과 `your_spells`를 사용한다. 신앙 수급과 XP 성장은 동결한다. 소모 비용은 실제 차감한다. 캐릭터·적·신 상태·RNG를 조우마다 초기화한다. 주문 취소에는 비용 반환·무턴 처리를 적용하며 다음 행동의 상태를 남기지 않는다.

## 검사

- 비활성 모듈이 기준군에 효과를 남기지 않는지 확인한다. 기존 노엘·소피아 데이터와 겹치는 근접 결과는 HP·MP·신앙·시간·행동·승패로 비교한다.
- 모든20개 신규 모듈을 실제 몬스터가 있는 원작 세계에서60회 행동시켜 비용·자원 음수·HP 상한 변경·발동 누락을 검사한다.
- 마지막 적의 매료가 승리로 바뀌지 않는지, 만료 때 적으로 돌아오는지 검사한다.
- 마지막 적이 없어도 보류 피해를 지급하고 이 피해로 실제 HP가0 이하가 되는지 검사한다.
- 열기 획득 상한·자해 제외·rF+++ 적의 원작 면역·저항 중첩, 웅덩이의0피해 제외와 이동에만 적용, 연회의 과음 화력 보너스 제거를 검사한다.
- 시약의 첫10 aut 독 틱, 잔류물 소비, 자기 연소 피해, 임계 열충격의 AC 감소/종료, 점액의 적·아군 이동 지연, 도포의 빗나감 유지·피해0 명중 소비를 검사한다.
- 분신의 실제 HP1/EV와 통과 소멸, 까마귀6마리 생성·비행·첫 행동 대기·자기 이동 에너지·공격 간격·보호막·플레이어와의 자리 교환을 검사한다.
- 전시 교체 비용·AC·작품 휴식 지속과 공예 상태 감소, 대혼란 피날레의 이동 및 박수 비용을 검사한다.
- 실제 원작 전투에서 방어로 HP 피해가0이 된 명중을 별도로 만들어 열기·도포·까마귀 명중 기여가 전달되는지 검사한다. 쌍섬의 실제 처치 직후 제한 해제와 MP 환급이 발동 완료 처리에 덮이지 않는지도 검사한다.
- 정방향과 역방향 일괄 실행의 같은 조우가 모두 일치해야 한다. 부분 출력은 전체 재현 검사 통과로 인정하지 않는다.

## 해석할 때 유지할 제한

- 전투 코어와 자동 운용 정책의 첫 비교다. 박수·시약·정원 등 사전 준비와 전투 사이 자원 보존은 없는 시작 조건이다. 최적 수동 운용의 모든 분기와 보스별 면역, 정상 숭배 UI·저장·층 이동·징벌은 아직 별도 검증 대상이다.
- 식물·분신·까마귀는 원작의 단일 물리 공격을 가진 몬스터 객체를 바탕으로 명시한 수치와 행동을 적용했다. 새 몬스터 종을 일반 던전 생성표에 등록하지 않았다.
- 정신 면역 분류는 원작의 비자연·무지능 판정을 공통 기준으로 삼는다. 특정 보스의 별도 지배 면역 표는 일반 모드 통합 때 별도 확인해야 한다.
- 시간 효과는 원작 몬스터 단계 뒤의 위치로 논리적인 주기를 처리한다. 긴 행동 중간의 모든 위치를 복원하는 연속 이벤트 시뮬레이터는 아니다. 특히 지원사격의 동시 후보, 경계 진입, 긴 행동 중 범위 체류는 이 단계 순서의 영향을 받는다.
- 고정 적에 대한 자동 전투다. 일반 탐색·발견·도주·회복약·소모품·장비 교체 전략은 비교하지 않는다.
