# 집에서 이어하기 · 2026-10-21 · LAMY_CASTER01

## 현재 멈춘 곳

라미의 마법사 개편 1·3·5성 전투 수치를 실제 적용했다. 아직 사용자가 라미 연출을 승인하지 않았다. **다음 작업은 1성 ‘설국의 잔’ 인게임 GIF를 보고 사용자의 피드백을 받는 것**이다. 자동으로3성이나 다른 신으로 넘어가지 않는다. 토와는1·3·5성 전체 최종 승인.

## 집에서 시작

1. ZIP 전체를 **새 폴더**에 푼다.
2. `OPEN_VFX_REVIEW.cmd`를 실행하면 라미1성 미리보기가 열린다. 파일로 바로 열리므로 미리보기 서버가 필수는 아니다.
3. 게임은 `PLAY_HOLOCRAWL.cmd`. Windows x64 실행본과 의존 DLL을 포함했다. 처음에는 게임 데이터베이스를 만든다.
4. 파일 무결성은 `VERIFY_HOME.cmd`로 확인한다.
5. 집 코덱스에 이 폴더를 열고 **“CONTINUE_HERE.md를 읽고 라미1성 검토부터 이어가자”**라고 한다.

## 이전 기록과 재빌드

`analysis/handoff-history/company-before-home-lamy01/`에는이전인계문서를보존했다.그곳과다른옛보고서의“라미미구현/토와검토중”등은과거기록이다.현재상태는이문서와현재JSON을우선한다.이전도입당시TRANSFER_MANIFEST는히스토리에보존하고,ZIP루트에는이번전달파일전수해시를새로기록했다.

실행·미리보기에는컴파일러가필요없다.용량을줄이기위해`.toolchain`컴파일러전체/오브젝트/데이터베이스캐시/중복과거실행본/대규모조우원시데이터는제외한다.이항목들은회사원본폴더에보존했다.집에서코드를다시빌드할때는기존집작업폴더의MSYS2/MINGW64 `.toolchain`을재사용한다.새프로젝트의`.toolchain/msys64/usr/bin/bash.exe`와`mingw64/bin/python.exe`경로가연결되면기존빌드스크립트가그대로동작한다.개인키·계정정보·컴파일러사용자홈은묶지않는다.


전달 용량을 줄이기 위해 각 신 캡처 실행에서 반복 생성된 다른 신 원시 프레임은 제외했다. 승인·검토 GIF/미리보기 전체와 해당 신 핵심 원본 프레임,소스·도트·검증 JSON은 포함했다. 전체 중복 캡처 ZIP은 회사 원본 exports에 별도 보존했다.
