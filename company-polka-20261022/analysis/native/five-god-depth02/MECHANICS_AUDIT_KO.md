# 메라 화염 빔 방어 경로 — 정적 감사에서 발견한 구현 누락

2026-10-20 본 코호트 실행 중 발견했다. 실행 도중 동결한 소스나 기획 수치는 수정하지 않았다. 이 문서는 데이터 완전성/재현 검사와 별도의 구현 적합성 지적이다.

## 확인한 경로

1. `engine/five-god-crawl/crawl-ref/source/beam.cc:3807`에서 실제 `final_dam`을 `check_your_resists(..., false)`로 계산한다.
2. `ouch.cc:284`는 `doEffects == true`일 때만 `holo_batch::elemental_damage`를 호출한다. 따라서 위 실제 피해 계산에서는 메라 궁극기의 추가 화염 피해 절반 처리가 호출되지 않는다.
3. `beam.cc:3824`에서 메시지/상태 처리를 위해 `check_your_resists(..., true)`를 다시 호출하지만, 반환값을 버린다.
4. `beam.cc:3953`은 처음 계산한 `final_dam`으로 `internal_ouch`를 호출한다. `holo-batch-experiments.cc:279`의 추가50% 감소는 이 실제 빔 피해 값에 반영되지 않는다.

이는 정적 제어/데이터 흐름으로 확인한 **화염 빔 경로의 누락**이다. 메라의 기본/궁극기 화염저항 자체가 전부 무효라는 뜻은 아니다. 화염저항 수치는 별도 `player_res_fire` 경로에 들어간다. 구름·끈적이는 불꽃·아군 방어에는 별도 `fire_protection` 경로도 있으므로 전부 같은 결함이라고 일반화하지 않는다. 다른 화염 피해 경로 역시 각각 종단 검사가 필요하다.

## 이번 결과의 해석

- 새 코호트는 이 결함이 남아 있는 현재 구현 기준이다. 소환수 연결 제거의 실제 충돌만 먼저 수정한 고정 소스를 사용했다.
- `화염 방어 제거` 변형은 기본/궁극기 화염저항과 추가 감소 처리 전체를 함께 끈다. 관측된 승률 차이를 기획상 추가50% 감소의 개별 기여로 읽을 수 없다.
- 원래8상황에는 이 문제의 화염 빔을 쓰는 적이 없다. 여기서 화염 방어 제거의 차이가0이어도 화염 방어가 불필요하다는 결론이 아니다.
- 자료의 완전성·해시·시드·재현 검사 통과와 모든 권능의 기획 적합성 통과는 구분한다. 이번 전체 데이터의 감사 성공으로 이 누락까지 해결됐다고 주장하지 않는다.

## 다음 수정의 수용 기준

이번 동결 실행에 섞어 고치지 않았다. 별도 수정 단계에서 실제 적 화염 빔으로 HP 감소량을 비교하는 종단 회귀 검사를 먼저 만들고, 기본/궁극기 화염저항과 추가50% 감소가 각각 정확히 한 번 적용되는지 확인해야 한다. 메시지용 재계산에서 이중 적용·쓸모없는 난수 소비가 생기지 않도록 한다. 구름·끈적이는 불꽃·아군 경로도 중복 감소 여부를 검사한다. 수정된 엔진은 다른 버전/출력으로 재검증하고 현재 결과를 덮어쓰지 않는다.

새 테스트나 수정 전에는 이 경로를 네이티브 종단 회귀 시험으로 검증했다고 부르지 않는다. 메라의 방어 수치 조정은 이 구현 누락을 고친 뒤 판단한다.
