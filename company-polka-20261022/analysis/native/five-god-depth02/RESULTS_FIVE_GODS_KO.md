# 다섯 신 권능·면역·사전준비·연속전 검증

**52,500개 단일 조우 + 3,000개 연속전 묶음의 실제 5,842조우, 총 58,342조우 검사 통과.**

**위 통과는 자료 완전성·재현·지정된 검사 기준이다. 별도 정적 감사에서 메라 궁극기의 화염 빔 추가50% 감소 누락을 확인했으며 이번 소스에는 고치지 않았다. 전체 권능의 기획 적합성까지 통과한 것은 아니다. [메라 구현 감사](MECHANICS_AUDIT_KO.md)를 함께 읽어야 한다.**

- 메라·비비·미코·루이·폴카의 승인 수치와 원래 엔진은 유지했다. 별도 엔진에서 권능 생략·사전준비·자원 민감도를 비교했다.
- 단일 조우는 910000~910049의50시드, 14상황,25종,3빌드. 기존8상황과 새로운6상황은 별도 집계한다.
- 현재 비교의 기본 운용은 원래v3 정책이다. 직전 정책 확인에서 고른 선택적 운용과 혼합하지 않았다.
- 근접 빌드는 적과 인접해서, 사격·주문 빌드는 거리5~6에서 시작한다. 근접 빌드의 사격/주문 적도 인접 시작이다. 빌드 사이 차이는 무기 유형 하나만 바꾼 비교가 아니며 같은 빌드 안의 대조를 우선한다.
- 주문 빌드는 MP에 따라 화염의 화살/불꽃 투척/마법의 화살을 고르는 고정 AI다. 화염저항에 맞춰 다른 속성 주문으로 교체하지 않는다. 화염용·정령 상대의 주문 결과는 이 정책 제약도 포함하며 다양한 주문 빌드 전체를 대표하지 않는다.
- 19개 변형 × 3빌드=57개 기본상황 비교는 같은 시드의8상황을 묶었다. 개별95%와57비교 Bonferroni 가족95% 정규근사 구간을 JSON에 보존한다. 아래 개선/악화는 보정 구간이0을 벗어난 경우이며, 불확실은 동등성 판정이 아니다.
- 실험 계획·정책·소스는 사전 검사와 본 코호트 전에 기록했다. 권능 생략은 비용·행동·후속 자원도 바꾸므로 총효과 비교다. 효과끼리 더해서 전체 기여를 만들 수 없다.
- 준비 신사3MP/10aut, 준비 까마귀6~9MP/20~30aut를 실제 지불하고 적을 배치했다. 시작 박수3/6은 비축 민감도이며 자연스럽게 공짜로 얻는다고 가정하지 않는다.
- 도전 적은 실제0.24 저항·상태 면역·AI를 쓴다. 서로 다른 적의 결과를 저항 하나만 바꾼 인과효과로 해석하지 않는다.

`effects.batch_damage`는 신 모듈의 직접 피해 카운터이며 일반 무기·기본 주문·까마귀의 기본 물리 공격을 전부 합친 총피해가 아니다. 효과 카운터는 준비를 포함한 누적값이다. 원시 자료의 `ap_*`는 공통 자원 슬롯 이름이고 폴카에서만 박수로 해석한다.

## 실행 무결성과 발견한 결함

- 최초 사전 검사(five-god-depth01)는 엘프마법사에서 실제 SIGSEGV로 중단했다. 부분 파일·실패 로그·GDB 스택을 보존했고 본 코호트는 시작하지 않았다.
- 범위 공격이 보관한 몬스터ID 중 일부가 앞선 공격으로 죽은 소환사의 연결 소환수 제거 때문에 무효가 됐다. 시험용 엔진에 생존/null 검사를 넣고 메라·비비·미코·폴카의 실제 연결 전투구체 회귀 검사를 추가했다. 수치 변경은 없다.
- 새02 실행은 실패한 데이터와 섞지 않았다. 기존v3의552행 완전 일치, 세 빌드의 정역순 사전 검사, 모든 원시 행·시드·종류 완전성, 원래 화염면역/실명불가, 준비 비용·시간, 연전 자원 연속성·박수 장부,6개 본 코호트의 역순 재현을 통과했다.
- 원래 기획/패치 해시는 유지되고 진단 소스는 실행 동안 동결됐다. 최종 원시 JSONL의 해시는 validation.json과 다시 대조했다.
- 공식 엔진에는 시험용 수정이나 선택 정책을 자동 반영하지 않았다. 모든 검토는 고정 장비·정해진 AI·제한된 적 패널에 한정된다. 정상 숭배·저장·신앙 수급·징벌·선물·캠페인 통합 검증은 남아 있다.
