# 굵고 단순한 제단 도트 스타일 — altars02

사용자 피드백: 이전 제단이 도트보다 고해상도 원화를 줄인 그림처럼 보였다. 기존 개별 제단 구조와 32×32 파일 크기를 유지하며, 명암·장식을 단순화하고 굵은 윤곽과 큰 색면을 갖도록 아트를 다시 생성했다.

내장 image_gen으로 기존 원화의 편집을 먼저 시도했으나 잔디테일이 남아 해당 시안은 `candidate-detailed-*`로 보관했다. 최종본은 이미지 참조 없이 동일한 22개 구조물 목록과 더 단순한 스타일 지시로 생성했다. 실제 생성 이미지가 엄격한 16×16 격자나 6~8색 팔레트를 보장하지 않으므로 그런 규격을 달성했다고 주장하지 않는다. 최종 네이티브 PNG는 32×32이며 이미지 편집 도구가 만든 알파를 유지했다. 가져오기에서는 셀 분리와 최근접 축소·배치만 한다. 첫째 줄이 명목 격자보다 아래로 내려온 원화 특성에 맞춰 행 사이 여백에서 잘라 둘째 줄에 윗줄 받침대가 섞이지 않게 했다.

변경은 22개 제단 PNG와 빌드된 텍스처다. 숭배 규칙, 저장 형식, 메뉴 문양, 전투 수치, 권능 효과 코드는 변경하지 않았다. 문자 실행본과 문자 검사 이력은 altars01을 그대로 사용한다.

SDL 빌드 후 6장 화면 내보내기, 22신 권능·시각 상태·저장 검사, 새 프로세스 복원, 문자 저장을 SDL에서 불러오기 검사를 실행했다. 제단 22개가 배치된 실제 게임 화면을 직접 확인한다. 봇 승률과 고정 전투 322개 검사는 외형만 바뀐 이번 단계에서 반복하지 않는다.
