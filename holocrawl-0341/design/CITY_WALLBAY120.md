# 벽 전면을 국소적으로 높인 소품 크기 비교120

2026-11-08. 사용자 피드백:119는 벽면 침범을 막았지만 소품이 너무 작아짐.119의 크기는 승인되지 않았다.

이번120은 **소품이 붙은 구간만 실제 벽 전면과 위쪽 마감을 높이는 비교 시안**이다. 전체 일반 벽 높이를 바꾸거나, 큰 소품만 기존 윗면 위에 다시 겹쳐 그리지 않는다.

- 기본 벽92의14픽셀 세로 면은 일반 구간에서 유지.
- 소품 뒤의 세로 면은 가운데24픽셀(y8~31)로 높인다. 양끝은18→15→11→8의 작은 모서리로 원래 벽 마감에 연결한다.
- 진열장의 그림 높이12→20픽셀. 아크릴 인형5×8→10×15, 티셔츠8×8→14×14. 멤버 선택과 종횡비 유지.
- 설비는 높인 전면 안에서 원래 크기에 가깝게 복원한다. 소품 그림과 콘크리트 전면은 별도 레이어이며, 소품은 높인 전면의 테두리보다 아래에만 그린다.
- 바닥15종·배치·충돌·계단·문·고정지형·일반 벽은 변경하지 않았다.119와 이전117/118도 보존.

`preview/wall-bay120/bay120.js`를 새 street120(1~3층)와 market120(4~7층)에 공통 연결했다. `prepare-wallbay120.py` → `check-wallbay120.cjs` → `export-wallbay120.cjs`로 재생성·검증·출력한다.
