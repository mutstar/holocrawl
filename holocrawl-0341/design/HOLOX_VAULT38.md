# holoX38 · 기존 돌죽 타일 스타일로 재구성

사용자 피드백:37의 소품 자체는 좋으나 기존 돌죽 타일과 이질적.
원인: 큰 정면2칸짜리 미니어처 장비, 지나친 디테일과 멤버별 강조색.

- 기존 city-layout07/assets/scene-reference.png를 스타일·스케일 참고로 사용.
- built-in image_gen으로 새 소품5개 생성.37원화/도트는 수정하지 않음.
- 각 소품32×32 한 칸. 보이는 부분 최대24×25,기존PixelReducer12색,투명배경 유지.
- 라플라스 작은 제단,루이 까마귀 받침,코요리 작은 시약병 실험대,클로에 장비 상자,이로하 칼1자루의 낮은 걸이.
- 기존2칸 점유를1칸으로 줄여 실제 그림과 충돌 범위 일치. 비어 있는 나머지 칸은 바닥으로 개방.
- 연구소9×9·입구·내부문·보상 위치 보존. 기존37은 비교용.
- 전투/네이티브 게임은 미연결. 사용자 스타일 검토 대기.
