# 좁은 비율 문 원화 재제작12 / 2026-11-04

사용자 요청: 비율 비교의 세 번째 가로문처럼 가로가 짧은 문으로 도트를 다시 제작. 앞서 제안했던 양문 전환을 승인한 것이 아니므로 기존 철제 외짝문 컨셉을 유지했다. 신규12는 사용자 시각 검토 전이다.

검토: http://127.0.0.1:8797/native-door12/

## 원화와 도트

built-in image_gen으로 닫힌 문을 새로 생성하고, 이를 편집해 열린 문을 생성했다. 원본2개를 워크스페이스에 복사했고 정확한 프롬프트·도구·처리 기록은 preview/native-door12/art-manifest.json에 있다. 기존 그림의 표시 폭만 조정했던10/11과 달리 새 생성 원화와 새32픽셀 PNG를 사용한다. 손잡이는 짧고 얇게, 프레임은 세로로 긴 비율로 구성했다.

생성 원화의 알파 경계를 잘라24×30으로 면적 축소/정규화하고14색으로 정리, 투명32×32캔버스의(4,1)에 배치했다. 원화가24:30 비율을 정확히 준수했다고 주장하지 않는다. 런타임에서는 이32×32PNG를 그대로 같은 타일 크기로 그린다. 가로/세로별24/32 폭 조절을 제거하여 두 방향 모두24×30 실루엣을 사용한다.

가로 벽은 양옆 문설주, 세로 벽은 위아래 연결과 옆면을 유지한다. 열린 문짝은 오른쪽에 남고 가운데와 바닥 쪽은 투명하다. 문 열림은 브라우저 표시 전용이다.

새 페이지에는 가로/세로 닫힘·열림4개를 항상 함께 표시한다. 그림 클릭 시 해당 위치·상태를 실제 지도에서도 확인할 수 있다. 6개 원본 지도, 문 위치 이동, 가로/세로 이동, 열기/닫기, 전체 지도/화면 이동을 지원한다.

## 보존·검증

이전11과 이전 원화/PNG는 보존했다. 새 폴더에서도 previous-fire-door-*32.png로 이전 PNG를 보관했다. 원본6지도, 시멘트 바닥, 승인된 계단·콘크리트 벽 재질은 유지했다. 실제 게임 엔진 실행·적용·몹/아이템 배치를 진행하지 않았다.

scripts/prepare-native-door12.py, scripts/install-native-door12.cjs, scripts/check-native-door12.cjs. 두 새 PNG가 이전 파일과 다름,32×32 캔버스와(4,1,24,30)알파경계,14색·304픽셀 이상 투명 여백, 닫힘 중앙 불투명/열림 중앙 투명,6지도×2방향 표시/열기·닫기,원본 지형 불변,그림 클릭 이동,모바일 폭·JS/이미지 오류 검증 통과.
