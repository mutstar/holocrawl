# 도시 랜덤 구조 예시04 / 2026-11-04

사용자: 기존 맵이 의도적으로 배치된 것처럼 보임. 사각 구획 하나를 반복하는 규칙과 벽 아래 일렬 진열이 원인임을 확인한 뒤, 돌죽처럼 여러 형태를 섞는 구현 예시 요청.

비교 페이지: http://127.0.0.1:8797/city-layout04/layouts.html

## 새 구조

1. 큰 광장·건물 덩어리: 겹치는 큰 공간, 내부 건물 섬, 주변 작은 공간, 비균일 연결.
2. 비정형 방·통로 연결: 독립적으로 위치/크기를 뽑은 사각·ㄱ자·십자·모서리 잘린 방과 여러 굴곡의 통로. 최소 연결 뒤 추가 우회 길.
3. 구불구불한 골목망: 방향을 유지하다 바뀌는 랜덤 보행 통로, 작은 마당, 가지 길과 막다른 길.

같은80×70 크기이며 자동 모드에서는 큰 구조부터 시드로 고른다. 이전 사각 구획도 비교용으로 남겼다. 실제 DCSS 생성기를 실행하거나 정확하게 이식한 것으로 보고하지 않는다. 원본0.34.1의 여러 레이아웃 선택 구조를 참고한 별도 브라우저 생성 예시다.

새 구조는 `generator.js`, 이전 것은 `legacy-generator.js`. 공통 거리/도트 렌더러는 이전 상점가 자산20종·멤버84명을 사용한다. 이미지 생성이나 실제 게임 실행은 하지 않았다.

## 배치 규칙 변경

상점/배송/쓰레기/빈 구역의 무작위 중심과 영향 반경을 먼저 뽑는다. 상점 전면은 상점 밀집 구역에 몰리고 빈 구역에서는 줄어든다. 바닥 소품은 벽 아래만이 아니라 네 방향 벽 주변과 넓은 공간에도 묶여 배치된다. 각 고체 소품을 놓을 때 연결성을 검사한다.

새 시작 계단은 방 목록의 첫 방에 고정하지 않고 열린 후보 중 랜덤으로 고른다. 출구는 연결된 먼 후보 중 고른다. 바닥 무늬의 독립 랜덤, 진열 재추첨의 결정성, 승인 계단12/06은 유지한다.

## 검증

`scripts/check-layout04-preview.cjs`:3유형×60시드=180지도에서 모든 바닥·계단 연결,시드 결정성,검토용 이동 지점의 바닥 유효성 확인. 자동30지도에서 세 유형 모두 선택됨. 실제 지형 지표도 다름: 광장형은3×3 열린 공간이 많고,골목형은 막다른 길이 많음. 브라우저 조작·모바일 넘침·오류 검사 통과.

아직 승인 전 예시다. 8~14층의 전용 테마 도트와 실제 게임 적용은 별도 후속 작업이다.
