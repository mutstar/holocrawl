# 잔향도시 첫 네이티브 층

## 범위

0.34.1 로컬 타일 엔진에서 승인된 잔향도시 지도와 도트를 사용해 빈 1층을 탐험하는 단계다. 22신의 전투 구현과 몹·바닥 아이템 배치는 진행하지 않는다. 캐릭터의 기본 시작 장비는 원본 설정 그대로다.

`PLAY_STREET.cmd`로 시작한다. 새로운 캐릭터는 80×70 지도에서 시작한다. 방향키 또는 숫자패드 이동, `o` 자동 탐험, `Ctrl-S` 저장은 원본 돌죽 기능을 사용한다. 계단은 지형으로 배치했지만 다음 층 연결은 별도 작업이므로 현재 사용 시 안내만 한다.

## 지도 연결 방식

1. 실행기가 새 시드로 승인된 `preview/street-vision01/generator.js`를 호출한다.
2. `scripts/export-street-map.cjs`가 지형·시각 타일 인덱스를 `HCSTREET1` 파일로 내보낸다. 이 단계에서 몹·아이템 후보는 제거한다.
3. `HOLOCRAWL_STREET01_MAP` 환경 변수가 지정된 실행에서만 `holo34-street.cc`가 D:1 생성 단계에 이를 읽는다. 크기·경계·계단·지형 종류·바닥 연결성을 검증한 후 실제 `env.grid`에 설치한다.
4. 벽은 불투명한 고체, 펜스는 시선이 통과하는 철창 지형, 계단은 실제 계단 지형이다. 이후 이동·시야·탐험 기억은 원본 엔진이 처리한다.

지도는 실행 전에 생성해 가져오는 방식이다. 엔진 내부에서 JS를 실행하거나 전체 14층을 생성하는 단계는 아니다. 저장된 층은 엔진의 기존 저장 자료를 사용하므로 다시 켤 때 새 지도 파일을 만들더라도 저장한 게임을 이어하면 기존 층을 불러온다.

## 도트

승인된 시멘트 바닥·벽·실외기·파이프·펜스 이미지를 기존 브라우저 좌표로 잘라 게임용 타일 아틀라스에 등록했다. 새로운 그림은 생성하지 않았다. 올라가는 계단은 승인12, 내려가는 계단은 승인06이다. 각 칸에 타일 이름을 등록해 저장 시 숫자 인덱스에만 의존하지 않는다.

`scripts/prepare-street-tiles.cjs`는 현재 미리보기 서버(8797)가 실행 중일 때 아틀라스 입력을 다시 만든다. 엔진 빌드는 `BUILD_STREET.ps1`, 실행 자료 준비는 `scripts/prepare-street-runtime.py`를 사용한다. 두 번째부터 도트가 바뀌지 않았다면 아틀라스 입력을 다시 만들 필요 없다.

## 후속 작업

다음 층 생성·왕복 계단·층별 저장을 연결한 후 잔향도시 14층의 구간별 공간·장식 변화를 적용한다. 이후 JP 분기와 커튼콜을 연결한다. 몹·아이템 배치는 그 뒤다.
