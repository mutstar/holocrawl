# 기존 원화 복원·다칸 바닥 소품114

뭇별:113은 너무 단순해졌다. 기존 디자인을 살리고 맵과 자연스럽게 어울리게,1×1을 고집하지 않기.113의 단순화 방향은 거절된 비교자료로 보존한다. 114는112를 기반으로 하며 승인한 벽 매립112를 유지한다.

## 디자인과 크기

기존15종 고해상도 투명 원화를 그대로 읽어 알파 경계 기준으로 새 실제 크기에 재샘플한다. 작은32px 썸네일을 단순 확대하거나 새 기하도형 디자인으로 대체하지 않는다. PNG 원본을 수정하지 않으며 원본 경로/해시는 source-designs.json. 팔레트는 기존108의 절제된 청회색/골판지색, 멤버도트와 대표색/선택함수도 유지한다.

1×1 작은 소품,2×1 낮은 상품 더미/카트/물류 등,2×2 큰 진열대·옷걸이·상자 더미를 혼합. 큰 원화의 종횡비를 유지해 공간에 맞추고 바닥 가까이 정렬한다. 실루엣에서 만든 짧은 남동향 투영 그림자+접지부를 사용한다. 픽셀 디테일을 과하게 없애는113 스타일은 사용하지 않는다.

## 배치와 충돌

layout114.js가112의 벽·계단·벽진열장 구조를 재사용하고 바닥 소품만 재배치한다. 각 후보는 실제 사각 점유칸 모두가 비어 있어야 하며, 계단/시작/출구3칸 안을 피하고 가구끼리 겹치지 않아야 한다. 배치할 때마다 전체 연결성을 검사한다. 큰 크기가 안 맞으면2×1 또는1×1로 줄이거나 배치를 생략한다. 큰 가구 비중에 맞춰 개수도 줄여 통로를 비운다. 실제 점유칸 전체를 장애물로 표시한다.

기존112와 지형 전체가 동일하다는 뜻은 아니다. 벽/계단/벽진열장은 같고, 바닥 장애물 배치는 바뀐다. '한 칸 배치112 비교'는 원래112 생성 결과로 돌아가며 플레이어도 시작점으로 재설정한다. 적·보상/상자 파괴 기능은 이번 작업 범위 밖이다.
