# 1~7층 벽 구조물 재구성122

2026-11-08. 뭇별이 전체 세로 면22픽셀의 벽121을 기준으로 채택하고1~7층 벽 구조물 재구성을 요청했다. 벽121의 형태·높이·색·모서리는 유지하고, 벽 부착물9종의 세부 구조와 설비 배치를 새로 정리했다.

## 구조물

| 종류 | 새 구성 |
|---|---|
| 아크릴 진열장 | 매립 프레임, 유리 칸막이, 선반, 아크릴 받침과 작은 멤버색 가격표. 인형10×15 크기 유지 |
| 의류 진열창 | 동일한 벽 프레임 안에 봉·걸이,14×14 티셔츠, 유리 구획. 멤버색 선택 유지 |
| 닫힌 셔터 | 가이드·반복 슬랫·아래 무게추·잠금부, 시드별 작은 찍힘과 금속 마모 |
| 반쯤 열린 셔터 | 위쪽 말린 금속과 아래 창고 재고를 구분. 기존 원화 속 상품 부분 재사용 |
| 공연 포스터 | 하나의 모니터 같은 외곽 박스 대신 낱장3개. 원래 포스터 이미지 재사용, 뒤층은 일부 모서리 찢김 |
| 배관 | 원래 금속 관·엘보·이음쇠를 재사용. 접촉 그림자와 시드별 작은 밸브 |
| 실외기 | 원래 팬·본체, 벽 받침, 벽에 닿는 그림자 |
| 환기구 | 기존 루버와 벽 매립 플랜지, 얕은 그림자 |
| 배전함 | 기존 본체·경첩, 하단 배선·고정부와 벽 그림자 |

원래 이미지 디테일을 재사용하고 코드로 프레임/고정부를 더했다. 새로운 그림체로 대체하거나 바닥 소품을 단순화하지 않았다. 소품은 y11~30 안에만 그리고, 위쪽 마감·오른쪽 옆면·바닥은 제외한다. 유리 표현은 전시품 사이에 넣어 인형과 의류를 덮지 않는다. 정상 벽을 별도로 덮는 솟은 받침은 없다.

## 층별 구성

| 구간 | 배치와 표현 |
|---|---|
|1~3층 | 기존의 희소 거리 배치 보존. 진열창2/작은 매대2/셔터2, 기존 벽 설비 위치와 택배·울타리 유지 |
|4층 | 기존 상점가 초입의 진열 비중 유지. 실외기·환기구·배전함3곳 추가 |
|5층 | 기존 밀집 진열 골목과 의류창 유지. 벽 설비4곳 추가 |
|6층 | 배송 적재 장소 주변의 사용 가능한 벽에 배관·배전함 등을6곳까지 배치 |
|7층 | 셔터 비중이 높은 기존 구성, 더 많은 작은 마모·금속 찍힘·포스터 찢김. 설비 최대6곳, 긴 벽이 부족하면 생략 |

새 설비는 기존 벽 진열물과 겹치지 않고, 계단/출구3칸·공연장 프리팹2칸을 피한다. 모든 설비는 벽에만 있으므로 바닥 점유·통로·충돌은 변하지 않는다.80개 검토 지도에서4층3개/5층4개/6층6개/7층5~6개가 배치됐다. 고유지형 내부 모티프·문과 적·보상은 이번 작업에서 변경하지 않았다.
