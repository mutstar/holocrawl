# 잔향도시 1~3층 소품 재연결118

2026-11-08. 뭇별 요청: 초반1~3층 거리 소품도 최신 벽에 연결해서 보여주기.

## 구성

- 실제 엔진107에서 추출한 정상 생성12시드×1~3층=36지도 사용. 벽92/기본문101/고정지형106과 원본 지형 그대로.
- 층마다 진열창2, 작은 매대2, 셔터2, 택배상자2~3, 쓰레기1, 울타리2칸. 실외기·환기구·배전함·3~5칸 배관을 노출된 벽에 드물게 배치한다. 4~7층의 밀집 상점가와 구분한다.
- 진열창은 승인한 매립112, 바닥은 크기115와 그림자·의류 수정117을 재사용. 기존 도트 디자인을 유지하며 벽 설비는 최신 콘크리트의 차가운 색상에 맞춘다.
- 고정지형과 바깥2칸, 문·계단 주변3칸을 피한다. 모든 계단 사이 기존 최단 경로를 보호하며 각 바닥 소품 배치 후 남은 모든 이동 가능 칸의 연결을 확인한다. 실제 점유칸은 검토 화면에서도 통과할 수 없다.
- 적·보상·상자 파괴드롭은 이번 요청 범위에서 보류한다.

## 검증

`python scripts/prepare-street118.py` → `node scripts/check-street118.cjs` → `node scripts/export-street118.cjs`.

36지도 원본SHA256 보존, 동일 시드 재현, 점유칸 비중복, 보호 구역 회피, 모든 계단·잔여 통로 연결 통과. 브라우저에서 네이티브 시야1081프레임0불일치, 소품329점유칸 차단, 문 그룹175회 열기→통과, 모바일 가로 넘침 및 페이지/리소스 오류0 확인. `preview/city-street118/validation.json` 참조.

`street118-review.png`는 동일 시드10786001의1·2·3층 실제 코드 렌더 장면을 잘라 나란히 정리한 이미지다. `floor1-overview.png`는1층 전체 지도. 층별 소품 테마가 고정되었다는 의미는 아니며, 같은 거리 소품군에서 배치가 달라진 예시다.
