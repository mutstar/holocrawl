# 잔향도시 4~7층 공통 상점가 · 구조물 초안25

2026-11-05. 사용자 요청: 홀로도리 초기 구역 구조물 분위기를 우리 테마에 맞게 재해석. 이전에 찾으려던 외관은 셔터+쇼윈도 원화가 아니라 파랑·분홍 간판의 공연장 입구였음을 사용자 확인. 4~7층을 각기 다른 도트 세트로 만드는 부담을 줄이고 공통 상점가로 묶는 방향에서 3종 제작. **현재는 검토용 초안이며 승인·랜덤 배치 통합 전이다.**

- 라이브숍 입구: 파랑·분홍 슬래시 간판, 유리 양문, 작은 쇼윈도.
- 굿즈숍: 파랑·분홍 차양, 넓은 진열창, 옆 출입문. 상품은 현재 단순 실루엣 초안.
- 작은 카페: 크림·코랄 차양, 컵·별 간판, 따뜻한 주문 창구.

원래 도시의 어두운 콘크리트·갈색 벽과 어울리는 골조에 간판/차양/진열창만 밝게 했다. 홀로도리 시설의 직접 복사나 실제 시설명 대응표가 아니라, 공통 테마에 맞춘 새 디자인이다.

내장 image_gen으로 각 구조물 별도 생성, 투명 RGBA 원화 모두 프로젝트에 복사. `design/market25-prompts.json`에 최종 프롬프트 전체 보존. 기존 PixelReducer로 알파 경계 추출·면적 축소·28색 수출. 각 PNG 96×64(가로32px 3칸, 높이2칸), 평평한 바닥 끝. 상부 벽체가 있는 위치에 붙이는 전면 구조물이며 아직 출입/상호작용은 연결하지 않음. 향후 배치 시 3칸 벽 전면과 상부 여유를 확인해야 함.

검토: `preview/market-structures25/index.html` (http://127.0.0.1:8798/market-structures25/).
원화·도트: 해당 폴더 assets. `art-manifest.json`에 생성 모드·프롬프트·크기·축소 기록. `street25.png`는 기존 시멘트/벽과32px 캐릭터를 이용한 크기 비교용 수동 배치 장면. 실제 랜덤 생성 지도/실제 게임 적용으로 오인하지 않음.

재수출: `scripts/export-market-structures25.cjs`. 브라우저 검증/장면 캡처: `scripts/check-market25.cjs` (3개96×64로드,오류없음,모바일오버플로없음). 기존 1~3층과8맵 검토판은 그대로 보존.
