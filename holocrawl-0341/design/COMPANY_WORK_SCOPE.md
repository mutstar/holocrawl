# 회사 작업 범위 / 2026-11-04 사용자 확정

실제 게임 실행·게임 엔진 적용·실플레이 검증은 나중에 한다. 사용자가 다시 요청하기 전까지 회사에서는 브라우저로 도트, 던전 구조, 배치 시안만 진행한다. 앞서 만든 네이티브 1층 시제품은 보관한다.

바닥은 무늬를 이어 맞추는 Wang 조건 없이 칸마다 독립적으로 랜덤 선택한다. 승인된 시멘트 재질과 명도를 유지한다. 같은 시드·바닥 번호·좌표에는 같은 타일이 나와야 하며 화면을 다시 그리거나 이동한다고 패턴을 다시 뽑지 않는다.

- 구조 검토가 우선이므로 몹·보상 후보는 이 미리보기에서 비운다.
