# 도트 전 신 규칙 정리 — 별도 조정 버전

뭇별의2026-10-20 전체22신 검토 승인에 따른 별도 부록이다. 원래 `HOLOCRAWL_DESIGN.md`와 v3 결과는 역사 스냅샷으로 보존한다. 이 문서는 아래의 설계 결정과 실제 구현 확인을 구분한다. 메라/비비 최종 계수는 새 탐색·독립 확인 뒤에만 확정한다.

## 실제 전투 코어에서 확인한 규칙

- 와타메 회피/방어 반격: 인접한 생존 적의 해당 방어 훅에서 `20+I`% 발동 판정, 발동 간격10aut, 명중 수치 `20+I`, 피해 `1d(6+floor(I/2))`, native 회피/방패·AC 적용. 미노타 고유 반격을 대체하지 않는다. 이번에는 수치를 바꾸지 않고 원문의 미정 명중을 이 구현값으로 명시한다.
- 코로네 피해 보류: 적용 가능한 적 공격 피해마다 `floor(피해/4)`를 부채에 더하고 즉시 피해에서 뺀다. 종료 후10aut 간격5회, 매회 `ceil(현재부채/남은횟수)`를 지급한다. 실제 합계는 원래 부채와 정확히 같아야 한다. 보류 지급이 다시 보류되거나 새 반격/자원을 생성하지 않는다. 휴식 중 사망도 사망이다.
- 초코 혼미: 현재 코어의 의미를 **10aut 이동 봉쇄**로 명시한다. 완전 행동 불능/마비나 주문 봉쇄로 설명하지 않는다. 공격·주문은 가능하며 정지형/구속 저항3 이상에게 봉쇄를 적용하지 않는다.5중첩과 재적용80aut 조건은 기존대로다. 정신 면역 분류는 현재 별도 코드 조건이므로 모든 무생물/언데드를 일괄 면역이라고 쓰지 않는다.
- 비비 실명: native `ENCH_BLIND`와 `M_UNBLINDABLE` 분류를 사용한다. 대상은 이동/공격할 수 있다. 적의 플레이어 시각 인식이 막히고 스크롤 읽기가 제한되는 등의 native 규칙을 따르며 모든 주문 금지/일괄 명중 감산 같은 새 효과를 만들지 않는다. 기억한 위치·표적 없는 주문·비시각 감지의 개별 동작은 통합 검사 대상이다. 실명 불가 warg 실제 전투에서 실명 제거 전후가 완전히 일치함을 앞선02에서 확인했다.
- 메라 화염 보호: 출동의 추가50% 감소는 기본 화염저항 처리 뒤 실제 화염 성분에 한 번 적용한다. 근접의 기본 물리 피해는 줄이지 않는다. 아군은 소화 범위 조건을 따른다. 빔의 메시지 재계산은 실제 피해/RNG를 추가로 바꾸지 않는다. 실제9경로144쌍 HP 검사는 통과했고, 최종 조정 코호트에서도 다시 확인한다.

## 공통 가입·해금 규칙 결정

다음은 정상 숭배 UI/신앙 경제 통합을 위한 설계 결정이다. 고정 조우에서 구현·검증됐다고 표시하지 않는다.

- 가입 초기 신앙15, 범위0~200. 해금30/75/120은 유지한다. 가입만으로1성 권능을 즉시 주지 않는다. 같은 신 재가입으로 초기 신앙/선물/자원을 반복 획득할 수 없다.
- 액티브의 해금·충분한 자원·합법 표적을 먼저 검사하고 비용을 한 번 차감한다. 실패한 합법성 검사에는 비용/턴/쿨다운을 부과하지 않는다. 비용으로 별 단계가 떨어져도 이미 성공한 해당 액티브는 정해진 지속시간까지 유지한다. 상시 패시브와 다음 액티브 해금은 현재 신앙으로 판정한다. 배교/강제 종료의 개별 규칙이 우선한다.
- 쿨다운은 문서에 명시한 발동/종료 시점에서 실제aut로 계산한다. 저장/불러오기·층 이동으로 초기화하지 않는다. 배교 시 신 자원과 효과는 각 절대로 지우되, 이미 발생한 피해 부채는 소멸시키지 않는다.
- 코로네 부채는 층 이동·배교·저장에서도 금액과 남은 지급 시각/횟수를 보존한다. 층 이동 시간도 실제 경과 시간으로 계산한다. 정상 저장 구현 때 정수 합계·중복 지급·만료 후 미지급을 검사해야 한다.

## 배교 공통 규칙 결정

이 수치들은 징벌 통합용 첫 설계 기준이며 이번 고정 조우 승률에 포함되지 않는다. 원래 신별 징벌 내용/피해식/20aut 경고/동시 제한/최소100aut는 유지한다.

- 배교 시 징벌 예산8회, 경험치 해소 예산 `max(200,40×배교 당시 XL²)`를 기록한다. 자연 생성 경험치 적에게서 실제 얻은 XP만 남은 경험치 예산에서 차감한다. 재가입/층 이동/휴식/소환물 처치로 해소하지 않는다.8회가 실제 발동했거나 XP 예산이0이 되면 해소한다. 배교 당시XL은 고정한다.
- 자신에게 보이는 자연 생성 경험치 적이 있는 전투 시간100aut마다25% 발동 판정을 한 번 한다. 신별 기존 징벌이 진행 중이면 새로 쌓지 않는다. 발동 간격 하한100aut. 평화로운 휴식/시야 밖 적만 있는 동안은 징벌 전투 시간을 누적하지 않는다. 저장/불러오기에서 판정 타이머·예산·진행 중 경고를 보존한다.
- 신별 특수 징벌 적은 XP/아이템/신앙/박수·열기 등 처치 보상을 주지 않는다. 무한 자원원이 되지 않는다. 해당 소환 개체와 경고를 일반 적의 자연 생성으로 오인하지 않는다.
