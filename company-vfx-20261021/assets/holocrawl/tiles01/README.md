# HoloCrawl tiles01 — 32×32 도트 첫 패스

내장 **imagegen**으로 원화 시트 2장을 생성한 뒤, 원본을 보존하고 격자 분할·알파 경계 맞춤·최근접 축소로 엔진용 32×32 RGBA 타일을 가져왔다. 게임에서 사용하는 파일은 `engine/campaign-crawl/crawl-ref/source/rltiles/holo/`에 있다.

- 22신 문양: 제단 선택 메뉴, 설명 선택 메뉴, 실제 가입한 제단 위에 표시.
- 소환물 5종: 장미·여우·까마귀·검객·사냥개. 기존 저장의 네이티브 이름·배교 속성으로도 외형을 인식한다.
- 설치물: 페코라 당근 폭탄.
- 효과 16종 × 2프레임: 일반/긴급 경고, 성역, 정원, 물, 중력, 고리, 화염, 전시, 스포트라이트, 서리, 리듬, 방패, 점액, 충격, 혜성.
- 예비 스프라이트 4종: 고리·경고·웅덩이·충격 단독 그림. 현재 연결에 사용하지 않는 예비 원화다.

[생성 프롬프트 전체](generation_prompts.json), [64개 파일·해시](manifest.json), [원본 시트](originals/), [도트 미리보기](sprites-preview.png), [효과 미리보기](effects-preview.png).

이 버전은 **신의 문양과 전투 가시 효과**다. 22명 캐릭터의 전신/얼굴 도트·플레이어 외형 교체·개별 권능의 긴 전용 애니메이션까지 완성한 버전은 아니다. 기본 돌죽 타일은 원래 소스의 라이선스를 유지하며 새 원화의 생성 경로와 원본을 따로 기록했다.
