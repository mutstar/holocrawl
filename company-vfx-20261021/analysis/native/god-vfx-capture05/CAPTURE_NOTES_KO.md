# 실제 게임 화면 캡처 기록

최종 성공은 god-vfx-capture05다. native SDL OpenGL 렌더러가 생성한 화면을 원본 PNG로 저장했다. 합성 효과를 덧그리지 않았다. 갤러리는 필드 영역을 최근접 확대하고 신 이름을 바깥에 배치했다. 원본 전체 화면도 연결했다.

22신에서 성공한 권능 사용 69회를 캡처했으며 각 호출마다 효과 2프레임과 같은 시점의 순간 효과 제거 상태를 저장했다. 호출 전후 전체 전투 상태와 난수 상태의 동일성을 검사했고 저장 후 새 프로세스 이어하기도 통과했다. 높은 HP/MP/신앙·고정 적/장비의 테스트 조건이므로 캠페인 플레이나 자연스러운 자원 운용을 나타내는 화면은 아니다. 패시브와 모든 권능 선택 분기를 전부 캡처한 목록도 아니다.

## 보존한 시도

- 01: 캡처 중 tile flavour 재구성이 난수를 소비해 실패. 부분 원본 보존.
- 02: 현재 난수 subgenerator만 분리했으나 명시적으로 지정된 다른 난수 스트림도 바뀌어 실패. before/after 서명 보존.
- 03: 난수 스트림을 모두 보존한 뒤 코요리의 AC 화면 조회가 빈 target 레코드를 추가하는 부작용을 발견. `find()` 조회로 고쳐 수치·기존 약화 결과를 유지했다.
- 04: 네이티브 상태/RNG·저장 검사는 통과했지만 일부 순간 효과가 몬스터 뒤에 가려져 프레임 픽셀 검사가 실패했다. 원본과 실패 기록을 보존하고 완료로 사용하지 않았다.
- 05: 순간 효과를 바닥 장판과 분리한 전경 레이어에 표시. 22신·69회·207장이 상태/RNG 보존, 저장 복원, 프레임 구별 및 효과 제거 화면과의 차이 검사를 통과했다.

테스트용 캡처 초기화만 모든 난수 스트림을 보존하며, 실제 권능 실행의 난수를 되돌리는 코드는 없다. 이전 게임 실행본은 before-play-HoloCrawl.exe에 보존했고 현재 플레이 실행본은 테스트를 통과한 capture-engine.exe와 바이트 단위로 같다. 전투 계수·비용·저장 형식 변경은 없다.
