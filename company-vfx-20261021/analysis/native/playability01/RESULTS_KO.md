## 이번 구현

- `a` 권능 화면: 신앙 단계·MP·신별 자원·보호막·남은 지속시간·회복시간·불가 사유를 표시한다. 시약·전시품·노엘 보급 진행도·소피아 충전도 따로 표시한다. 표적·지형 등 나머지 조건은 선택 시 실제 권능 코드가 판정한다.
- `^` 신앙 화면 또는 권능 화면의 `?`: 22신의 전투 콘셉트, 권능 비용, 신앙 수급과 금기, 배교 효과를 읽을 수 있다. 제단에서도 가입 전에 `?`로 설명을 고를 수 있다. 긴 설명은 네이티브 스크롤 화면으로 줄바꿈한다.
- 설명·상태 조회는 턴·MP·신앙·저장 속성·전투 상태·난수를 바꾸지 않는다. 22신 모두 실제 설명 창을 열고 닫아 검사했다.
- 이전에는 배교 기록만 저장했다. 이제 22신 징벌을 일반 월드 시간·전투·경험치·이동·회복·스탯 계산에 연결했다. 재가입으로 징벌 의무를 지울 수 없다.
- 범위 경고와 소환물은 층 이동 시 정리해 다른 층 같은 좌표에서 터지는 문제를 막는다. 시간제 디버프는 남은 절대 시간대로 유지한다. 소환물은 보상·아이템이 없는 임시 네이티브 몬스터다.

## 공통 임시 수치

원 기획에서 미정이었던 공통 발동 방식과 일부 소환물 스탯은 다음 값으로 먼저 연결했다. **밸런스 확정 수치가 아니다.**

| 항목 | 구현 |
| --- | --- |
| 새 배교의 징벌 횟수 | `min(6, 3 + floor(배교 시 신앙/60))` |
| 경험치 상환량 | `max(200, 40 * 배교 시 XL^2)` |
| 종료 | 남은 발동 횟수를 소진하거나 경험치 의무를 상환. 이미 시작된 마지막 효과는 지속시간까지 진행 |
| 반복 배교 | 남은 의무가 있으면 합산. 재가입은 삭제·축소·발동 연기를 하지 않음 |
| 발동 환경 | 시야 내 적대 몬스터가 있을 때만. 적 없는 휴식으로 징벌을 소모하지 못함 |
| 주기 | 첫 의무 발생 100 aut 후부터; 효과 하나가 끝난 뒤 최소 100 aut. 확률 대신 준비 완료 시 발동 |
| 중첩 | 여러 신을 버려도 활성 징벌은 전체에서 하나씩, 순환 선택 |
| 경고 | 범위 공격·공격 소환물은 20 aut 경고. 좌표 메시지로 표시 |
| 구 저장 | 기존 `wrath_remaining=8`과 남은 경험치는 보존 |
| 공통 공격 소환물 | 검객·사냥개·까마귀: HP `12+2*XL`, AC 0, EV 10, 명중 `14+floor(XL/2)`, 기본 공격력 `3+floor(XL/4)` |

표의 턴은 기본 10 aut 기준이다. 오카유의 +15% 행동 시간과 초코의 -25% 회복량은 소수 몫을 저장해 작은 행동·회복에도 누적 비율이 맞게 처리한다. 기존 Slow에 오카유 지연을 추가 중첩하지 않는다.
