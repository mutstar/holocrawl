# 혜성·도깨비불 외형 수정 — altars04

사용자 요청에 따라 스이세이 제단은 오각별 대신 둥근 머리와 대각선 꼬리의 청색 혜성으로, 메라 제단은 일반 불꽃·화로 대신 부유하는 청록·보라색 도깨비불로 바꿨다. 메라의 형태와 색은 사용자가 첨부한 인물 이미지의 양옆 불꽃을 참고했다. 라미를 포함한 나머지 20개 제단 파일은 altars03과 동일하다.

숭배·저장 규칙, 능력 수치와 기존 권능 이펙트 코드는 변경하지 않는다. 변경 대상은 제단 외형 2개와 생성된 SDL 텍스처다. 기존 32×32 파일 크기와 메뉴 문양은 유지한다.

SDL 빌드 후 실제 필드 6장 내보내기, 22신 권능·시각 모델·저장, 새 프로세스 복원, 문자 저장의 SDL 불러오기 검사를 실행한다. 22개 제단을 배치한 화면을 직접 확인한다. 문자 실행본은 코드 변경이 없어 altars01 검사 이력을 유지한다. 외형 변경 단계에서 봇 승률과 고정 전투 검사는 반복하지 않는다.
