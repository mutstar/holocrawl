# 전투 도트·효과 통합 — combat-art01

사용자가 요청한 순서대로 소환물, 권능 효과, 상태 아이콘, 플레이어 기본 외형과 신별 표식의 첫 패스를 구현했다. 기존 제단 22개와 메뉴 문양 22개는 그대로 유지한다. 원화와 프롬프트는 `assets/holocrawl/combat-art01/`에 보관한다.

게임에 가져온 타일은 74개이며 모두 32×32 RGBA다. 장미·여우·까마귀·검사·사냥개는 각각 두 자세로, 게임 턴에 따라 프레임이 바뀐다. 검사·사냥개는 현재 징벌 소환물이며 새 아군 권능을 추가한 것은 아니다. 원래 DCSS의 아군·적 표시는 그대로 유지한다.

권능 범위 효과는 16종 각각 두 프레임이다. 지속 범위 표시는 중앙을 비우고 모서리·테두리·파문을 사용한다. 경고는 노란 모서리, 긴급은 빨간 모서리와 십자 모양으로 구분한다. 메라 불꽃 효과는 제단과 같은 청록·보라 도깨비불 계열로 정리했다. 발동 애니메이션은 기존의 짧은 두 프레임이고, 새 장시간 연출이나 별도의 전투 타이머를 추가하지 않는다.

상태 아이콘은 8종을 8픽셀 이내로 가져와 플레이어 타일 모서리에 붙인다. 위왼쪽은 5성/일반 권능 활성, 아래왼쪽은 보호, 위오른쪽은 징벌 경고/긴급/활성, 아래오른쪽은 회복 대기/자원이다. 같은 모서리의 상태는 우선순위로 하나만 보여 동시에 최대 네 개다. 실제 저장 상태와 타이머를 읽으며 RNG·자원·턴을 바꾸지 않는다. 숫자와 정확한 상태 설명은 기존 권능 화면에 유지한다.

플레이어 기본 인간 체형은 2종이다. 숭배 전 인간 캐릭터에도 적용하며, 갑옷·무기·방패·모자·신발은 원래 장비 레이어를 유지한다. 다른 종족, 변신, 지정 몬스터 타일은 기존 모습을 사용한다. 렌더링 복사본에서만 몸체를 교체하므로 새 픽셀 ID를 캐릭터 저장 데이터에 넣지 않는다. 22신 장식은 기존 메뉴 문양을 8픽셀 이내로 재사용한 작은 표식이다. 22명의 홀로라이브 캐릭터 전신 도트를 만든 단계는 아니다.

검증: 문자·SDL 양쪽 22신 권능 58회, 상태·설명 반복 조회의 RNG/저장 상태 불변, 22신 활성 상태 저장 복원, 자연 처치 신앙 수급, 176회 숭배 직렬화, 새 프로세스 복원, 문자 저장의 SDL 불러오기를 검사했다. 소환물 5종, 두 까마귀 프레임, 물장판·도깨비불·보호 및 5성 표시·노랑→빨강 경고·제단을 포함한 실제 게임 화면 14장을 검사한다. 각 화면에서 새 인간 기본 몸체가 적용되고 장비 레이어가 그대로인 것도 확인한다. 고정 전투 비교 322개는 원본 balance01과 동일하다. 이는 전체 던전 승률 검증이 아니며 봇 승률 작업은 계속 보류한다.
