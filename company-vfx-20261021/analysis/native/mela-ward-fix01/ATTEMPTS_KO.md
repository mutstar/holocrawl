# 메라 화염 보호 — 실패 보존 및 실제 HP 회귀

원본 v3와 five-god-depth02는 수정하지 않았다. 별도 balance-crawl에서 수정했다. 최종 `validation.json`은 after06의9경로×16쌍 실제 HP 검사가 통과한 결과다. 후속 정책 병합 버전도 새 코호트의 사전 검사에서 같은144행을 다시 생성한다.

| 시도 | 결과/발견 | 처리 |
|---|---|---|
| before | 실제 raw60 화염 빔: native rF2 뒤20피해. 출동 추가 보호가 있어도20으로 동일 | 기대값10을 만족하지 못한 실제 결함을 먼저 재현. 실패 보존 |
| after01 | 플레이어 빔은 수정됐으나 아군 빔이0/0 | 시험 빔의 몬스터 대상 자동 명중에는 `hit=AUTOMATIC_HIT`도 필요.0피해를 성공으로 인정하지 않고 시험 설정 보완 |
| after02 | 실제 화염 정령 근접의 화염 성분은 보호를 우회 | `AF_PURE_FIRE`가 전달하는 성분의 실제 적용 경로 추가 조사 |
| after03 | 전체 근접 피해를 절반으로 비교하면4→3 같은 행이 실패 | 실제 공격에는 native 물리 최소 피해와 별도 화염 성분이 함께 존재. 실제 전달된 비화염 피해를 debug 탭으로 기록하고 화염 성분만 검사하도록 오라클 수정 |
| after04 | 순수 화염 추가타가 BEAM_NONE으로 전달되어 기록에서 물리로 분류됨 | 실제 전달 flavor를 BEAM_FIRE로 명시하고 공통 공격 전달 지점에서 한 번만 보호 적용. 기본 물리타 보존 |
| after05 | 빔·근접 통과, 구름 전 경로0피해로 실패 | native 구름은 완료된 턴과 양수 time_taken이 있어야 피해 적용. 시험을 정상10aut 완료 턴으로 구성. 비영 피해 요구 유지 |
| after06 |9경로×16쌍 모두 통과 | 최종 통과. 앞선 실패 파일·종료 코드·바이너리·화면 로그 모두 유지 |

검사 경로는 플레이어/아군 화염 빔, 플레이어/아군 실제 화염 정령 근접, 플레이어/아군 불구름, 플레이어 끈적불, 냉기 대조, 물리 대조다. 빔은 플레이어20→10, 아군60→30이다. 물리/냉기60은 그대로이며, 출동 만료 뒤 플레이어 화염 피해30(rF1)도 확인했다. 근접은 실제 비화염 피해가 동일하고 화염 성분만 절반±정수 반올림1인지 검사한다.

보호가 두 번 적용되거나 구름/근접 피해가 전혀 발생하지 않아도 성공하는 검사를 사용하지 않았다. 이번 수정은 화염 보호 구현 수정이며, 메라 브레스 수치 조정과는 별도 원인이다. 탐색/확인 코호트는 수정된 기준선과 조정 후보를 비교한다.
