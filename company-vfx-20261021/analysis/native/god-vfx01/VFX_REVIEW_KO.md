# 권능 시각 효과 점검 — god-vfx01

뭇별 요청: 공통 타격을 쓰던 10신을 신별 효과로 교체하고, 실제 권능 성능·기도술과 화면 표현의 차이를 점검한다. 전투 수치·자원·RNG·저장 형식은 변경 대상이 아니다. 아래 추가 후보는 구현 완료 목록과 구분한다.

## 22신 성능·기도술 점검과 추가 후보

## 구현 원칙

- 기도술 수치만 보고 장판 크기·공격 횟수·탄수를 임의로 늘려 그리지 않는다.
- 먼저 표시해야 하는 것은 실제 대상·범위·자원·남은 시간·명중/저항 결과다. 단순 위력 차이는 같은 범위 안에서 입자·명도 변화로 표현하는 후보이며 이번에 자동 도입하지 않는다.
- 지속 장판은 기존 `at()` 및 소피아 `visual_at()`의 저장된 실제 상태를 사용한다. 새 시각 효과 때문에 상태 갱신·RNG 추첨·턴 진행을 호출하지 않는다.
- 이번 10신 도트는 신별 공통 시전 알림이다. 위 표의 권능별 전용 연출·공격 경로·성공/실패 연출을 모두 구현했다는 뜻은 아니다.

## 전달본 재빌드 복구

ZIP에서 `Makefile.obj`가 객체 파일 확장자로 잘못 제외돼 있었다. 보존된 wrath02 스냅샷의 원본 해시와 일치하는 파일을 복구했고, 패키징 필터에 이 파일의 예외를 추가했다. 또한 이전 PC의 pkg-config 기본 include 중복으로 GCC `include_next`가 실패하는 경로를 피하도록 번들 SDL/FreeType/PNG의 위치를 빌드 스크립트에 명시한다. 첫 실패 로그는 보존하며 이를 빌드 성공으로 취급하지 않는다.
