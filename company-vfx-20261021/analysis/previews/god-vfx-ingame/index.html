22신 · 실제 인게임 권능 사용 화면

실제 SDL 게임 렌더러에서 성공한 권능 직후 저장한 화면입니다. 필드 11×11칸을 확대했으며 원본 전체 화면도 열 수 있습니다. 테스트 전투장·고정 장비·높은 HP/MP/신앙을 사용하며 일반 던전 플레이 영상은 아닙니다.
아래 움직임은 실제 두 프레임을 0.55초 간격으로 반복한 비교용입니다. 게임의 원래 효과 속도와 다릅니다. '효과 제거 후'는 같은 시점에서 순간 시전 알림만 지운 화면이며, 턴을 추가 진행한 장면이 아닙니다.
권능 선택 목록은 이번 실행에서 캡처한 호출만 포함합니다. 패시브·모든 선택 분기·명중 결과를 전부 보여주는 목록은 아닙니다.

권능 해금: 1성 신앙 30 / 3성 75 / 5성 120. 자동은 조건을 만족할 때 적용되는 가호, 사용은 직접 고르는 권능입니다. 각 카드 아래에 1·3·5성의 실제 효과와 화면 표시를 구분해 적었습니다. MP/신앙 비용은 선택 장면의 실제 영어 메뉴를 함께 확인하세요.
같은 신의 여러 권능이 같은 순간 효과를 공유할 수 있습니다. 순간 효과의 모양 자체가 피해 범위나 제어 성공을 뜻하지는 않습니다.
